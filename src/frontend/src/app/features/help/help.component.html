Guide

Comprendre les motifs d'absence, les groupes et le fonctionnement de la prédiction.

Comment fonctionne l'application

1

Employés — gère la fiche de chaque salarié (données démographiques et liées au trajet).

2

Prédictions — pour une absence (employé + motif + date), le modèle estime la probabilité qu'elle soit excessive.

3

Dashboard — agrège les absences par groupe de motif et suit la performance du modèle.

Les 4 groupes de motifs

Chaque code de motif (0–28) est rangé dans l'un de 4 groupes, utilisés comme variables par le modèle.

Lexique

Absence « excessive »
Absence dont la durée dépasse le seuil appris par le modèle (médiane des heures d'absence). C'est la cible que le modèle cherche à prédire.
Probabilité
Confiance du modèle (0–100 %) que l'absence soit excessive. Au-delà de 50 %, la décision affichée est « excessive ».
Accuracy
Proportion de prédictions correctes, toutes classes confondues.
Precision
Parmi les absences prédites « excessives », combien le sont réellement.
Recall
Parmi les absences réellement excessives, combien le modèle a su détecter.
F1
Moyenne harmonique de la précision et du rappel (équilibre entre les deux).
ROC AUC
Capacité du modèle à distinguer les deux classes (0,5 = hasard, 1 = parfait).
